# ver.1 — исходное решение

- Для соревнования: **submission.csv**.
- Решение с выполненными ячейками: **homework_03.ipynb**.
- Все файлы и исходные данные: **homework_03_complete.zip**.

Итоговая модель — LinearRegression логарифма цены с One-Hot, сочетаниями категорий, полиномиальными признаками и временным трендом. MAE на октябре–ноябре 2012: 734 837; на декабре: 791 467. Ridge в ноутбуке только для сравнения, не для итогового прогноза.

Для повторного запуска положите три CSV в `data/` рядом с ноутбуком, в `../data/` или рядом с ноутбуком. Выполните все ячейки. Версии библиотек — в requirements.txt.
