# ver.3 — последняя попытка

- **submission.csv** — файл для соревнования.
- **homework_03.ipynb** — самодостаточный выполненный ноутбук.
- **linear_v3.py** — тот же класс модели отдельным модулем.
- **validation_results.csv** и **metrics.json** — локальная проверка.
- **preliminary_trends.csv** — предварительное сравнение других форм временного тренда.

Основной алгоритм — взвешенная LinearRegression логарифма цены. Признаки и веса объектов сохранены от ver.2; изменена форма временного тренда. Сравниваются логарифмическое замедление и ограниченный линейный рост, выходящий на плато после 18 месяцев с января 2011 года.

Проверка: обучение до октября 2011 → октябрь–декабрь 2011; обучение до октября 2012 → октябрь–декабрь 2012. Для сравнения ver.2 повторно оценивается на тех же разбиениях. В прежней таблице ver.2 второй период включал только октябрь–ноябрь, поэтому нужно использовать новую парную таблицу, а не сравнивать числа из разных протоколов.

Локальная валидация многократно использовалась при подборе, поэтому не является новой независимой оценкой. Выход на плато — гипотеза о будущем; улучшение public/private не гарантируется. Public для ver.3 ещё не проверен.

По формуле соревнования Public = 1 / (1 + MAE): большее значение Public лучше. Это не то же число, что отдельно показываемое интерфейсом поле «Баллы».

Данные положите в `data/`, `../data/` или рядом с ноутбуком и выполните все ячейки. Зависимости — requirements.txt. Используются только линейные модели.

Проверенный средний MAE на одинаковых двух временных разбиениях: ver.2 — **646,113**, ver.3 — **620,808** (снижение на 3,92%).
