# ДЗ 3: линейная регрессия для цены недвижимости

## Что сдавать

- `homework_03.ipynb` — выполненный ноутбук с пояснениями, графиками и результатами.
- `submission.csv` — файл для соревнования: 100 000 строк, столбцы `id,price`.

Итоговый алгоритм — `sklearn.linear_model.LinearRegression`: модель логарифма цены с обратным преобразованием через exp. Использованы заполнение пропусков, масштабирование, One-Hot, сочетания категорий, полиномиальные признаки и временной тренд. Деревья и бустинг не используются. Ridge включён только как дополнительный эксперимент, не в финальный прогноз.

## Проверенные результаты

| Проверка | MAE |
| --- | ---: |
| Медианная константа, validation | 2 863 145 |
| Итоговая конфигурация, validation | 734 837 |
| Контрольный декабрь 2012, выбранная модель | 791 467 |
| Контрольный декабрь 2012, медианная константа | 2 736 558 |

Validation — октябрь–ноябрь 2012; обучение вариантов — более ранние месяцы. Декабрь оставлен для отдельной проверки после выбора конфигурации. После контрольной проверки модель переобучена на всём train для submission. Конкурсный test не содержит ответов, поэтому его MAE и балл неизвестны.

В исходных файлах периоды train и test частично перекрываются. Ноутбук преобразует строки дат в календарные даты и не опирается на порядок строк. Подробности и ограничения экстраполяции описаны в ноутбуке.

## Как повторить

1. Распаковать архив. Оставить три исходных CSV в папке `data` рядом с ноутбуком.
2. Открыть ноутбук в Jupyter или загрузить в Colab вместе с CSV (в Colab CSV можно положить прямо в текущую папку).
3. Выполнить все ячейки по порядку. Готовый `submission.csv` будет перезаписан новыми результатами.

Проверено на Python 3.12, scikit-learn 1.8.0. Точные версии в `requirements.txt` (Python 3.11+). При необходимости установить зависимости командой `python -m pip install -r requirements.txt` в своём окружении; интерфейс Jupyter/Colab предоставляется отдельно.

`validation_results.csv` — сравнение всех вариантов; `metrics.json` — выбранная конфигурация и метрики. Ноутбук автономен: вспомогательные скрипты из рабочей среды не нужны.
