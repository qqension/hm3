## Сравнение

Обе итоговые модели используют `LinearRegression` для логарифма цены. В ver.2 добавлены сочетания категорий и умеренные веса обучающих объектов. Деревья и бустинг не используются.

| Локальная проверка | ver.1, MAE | ver.2, MAE |
| --- | ---: | ---: |
| Среднее двух временных разбиений | 751 725 | 644 409 |
| Декабрь 2012 | 791 467 | 621 325 |

Средний MAE снизился на 14,3%. Декабрь уже использовался в ver.1; для ver.2 это повторная диагностика, не новый независимый holdout. По сообщению пользователя Public ver.2 равен примерно **0.00000130**, поле «Баллы» — **999 998.69561537**. По формуле Public = 1 / (1 + MAE) большее значение Public лучше. Private неизвестен. Пользователь сообщил public-балл ver.1: **999 998.99102410**; это значение интерфейса соревнования, не локальный MAE.
